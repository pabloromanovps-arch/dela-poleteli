# Библиотека референсов студии

Сюда складываются референсы: кадры, видео, ссылки. Арт-директор опирается на
неё на стадии 01 (скилл `art-direction`).

## Как добавлять
1. Кидаете файлы в `_inbox/` (или ссылки списком в `_inbox/links.md`).
2. Просите: «разбери референсы» — Claude смотрит каждый, раскладывает по
   папкам и дописывает запись в `index.yaml`: что в нём сильного (свет, ритм,
   типографика, переход, материал), теги, автор/студия.
3. Крупные видео лучше хранить ссылкой или в облаке — git не для гигабайт
   (см. `.gitignore`: видео > по умолчанию игнорируются, кадры PNG/JPG — нет).
