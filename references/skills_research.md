# Ресёрч дизайн-скиллов: что проверено, что взято

Правило: сторонние скиллы читаем, код не ставим. Берём принципы, переписываем своими словами,
указываем источник. Лицензию проверяем до дословного копирования.

| Источник | Лицензия | Вердикт |
|---|---|---|
| Anthropic `frontend-design` | уже в окружении | Используем как есть для веб-вёрстки; из него взята калибровка списка «слопа» |
| Impeccable | Apache-2.0 | Код НЕ ставим (при первом запуске качает бинарник). Взяты глаголы доработки: упростить, усилить, приглушить, отполировать |
| taste-skill | MIT | НЕ ставим (нужны Node, Chrome, сеть). Взято: «сдача трёх направлений», запрет шаблонных сочетаний |
| Owl-Listener designer-skills | MIT | Принципы критики: линзы плотности информации и согласованности с брендом |
| Emil Kowalski (скиллы по анимации) | лицензия не проверена | Только пересказ, без копирования: правила easing, motion маскирует размытием |
| remotion-motion-designer | MIT | Три слоя движения: основное, вторичное, фоновое; драматургическая дуга |
| `video-shotcraft` (уже в окружении) | см. плагин | Прочитаны aesthetic-rules и music-beat-sync. Взято: R1–R4 ритм, Q11 минимальный размер текста, S1–S5 звук |
| `superdesign`, `codesign` (IMG.LY) | в окружении | Не основной путь: codesign нестабилен. Используем по необходимости |

## Что внесено в скиллы студии
- `art-direction-taste`: перечень предмета из 8–12 пунктов; «аргумент» к каждому разделу; голый минимализм читается пустым без материала.
- `film-and-motion-craft`: размытие маскирует склейку; три слоя движения; кривая и пружина выбираются по смыслу; барьеры ритма.
- `design-critique`: глаголы доработки; линзы плотности и согласованности; проверка в размере показа.

Не проверялось: ни один из внешних скиллов в работе на наших проектах не запускался.
