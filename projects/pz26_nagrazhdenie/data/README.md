# data/laureates.csv — слоты лауреатов (ТЕСТ: заглушки)
35 строк = 7 категорий × 5. Имена, компании и фразы — **синтетические заглушки** (с крайними длинами для проверки вёрстки).
Реальные данные подставляются в тот же файл — пересборка карточек и клипов = одна команда (data-driven-templates).
Колонки `portrait`, `action_clip`, `interview_clip` — пути к материалам лауреата (пока пусто). `skip=1` — пропустить строку.
Список реальных лауреатов и категорий — запросить у клиента (письмо 01).
