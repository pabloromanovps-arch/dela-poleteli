# Композитинг

## Порядок слоёв (снизу вверх)
1. Фон / окружение → 2. CG beauty (или пересборка из проходов: diffuse + glossy +
   emission + …) → 3. Атмосфера (mist/depth → туман, лучи) → 4. Графика/текст →
5. Свечение (от emission/яркостей, в линейном) → 6. Линзовые эффекты (виньетка,
   лёгкая хроматика по краям, блики — умеренно) → 7. Грейд → 8. Зерно/дизеринг.

## Правила «дорогой» картинки
- Свечение — многоуровневое (несколько радиусов), а не один Glow.
- Глубина резкости — из прохода Depth, с осторожностью на тексте.
- Зерно/шум 1–2% — убирает «цифровую» чистоту и бэндинг; для LED — мелкое,
  без мерцания крупных пятен.
- Cryptomatte — для точечных правок цвета объектов без перерендера.
- Никаких «эффектов ради эффектов»: каждый слой композа решает задачу из библии.

## AE
Плагины по наличию у пользователя (Deep Glow, Optical Flares, Red Giant,
EXR-tools встроенные с 2022+). Скрипт автосборки многопроходного EXR (`tools/ae/comp_from_exr.jsx`) — в
планах (`ROADMAP.md`); пока проходы раскладываются по порядку выше вручную или
через Blender Compositor.

## Blender Compositor
Для пакетных и полностью скриптовых сборок — ноды строятся в `build_scene.py`
(раздел `comp` в спеке).
