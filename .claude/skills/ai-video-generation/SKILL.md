# Видеогенерация

## Дизайн шота под нейросеть
- **От кадра, а не от текста**: стартовый кадр — утверждённый ключевой; при
  необходимости финальный кадр (start/end) — так шот приходит куда нужно.
- **Одно действие и одно движение камеры** на шот. Сложное действие — серия
  коротких шотов, монтаж спрячет швы.
- **Короткие шоты** (обычно 2–6 с) держат качество лучше длинных; длинный план —
  стык по последнему кадру предыдущего шота.
- Опасные зоны: крупные лица с речью, руки с мелкой моторикой, текст, быстрые
  повороты, толпы, физика жидкостей — закладывать больше попыток или решать
  монтажом/композом.

## Описание движения (в shots.yaml)
```yaml
- id: sc02_sh030
  start: ai/selects/sc02_sh030_v03.png
  end: null
  action: "героиня медленно поворачивает голову к окну"
  camera: "медленный наезд, без панорамы"
  duration_s: 3.75      # кратно доле трека
  model: "<сервис и версия>"
  attempts: 6
  selected: ai/shots/sc02_sh030/take04.mp4
```

## Пост-обработка шота
1. Отбор дубля (design-controller).
2. Апскейл до разрешения проекта (профиль экрана) — инструмент и настройки
   записать.
3. Интерполяция до fps проекта (если модель даёт меньше).
4. Дефликер/стабилизация, если нужно.
5. Экспорт в мезонинный формат (ProRes / PNG-секвенция) для сборки, без
   пережатия.

## Сборка сцены
Шоты → монтаж по бит-сетке (editor) → композ, типографика, графика поверх
(compositor / motion-designer) → цвет (colorist) → звук. Проект сборки — в
`06_build/`, редактируемый.
