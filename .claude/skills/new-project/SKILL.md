# Новый проект

1. Спроси (или возьми из запроса): короткий id латиницей (`2026_vtb_forum`),
   название, клиент, площадка/экран.
2. Выполни: `python tools/new_project.py <id> --title "<название>" --screen <profile>`
   (профиль — имя файла из `screens/` без `.yaml`; нет подходящего — `custom`,
   и задача TD заполнить профиль).
3. Открой `projects/<id>/project.yaml`, проверь, что стадия `00_brief`.
4. Передай работу роли `producer` для заполнения брифа.

Шаблон лежит в `projects/_template/`. Не меняй шаблон под один проект —
меняй копию.
