# LED и сдача

## Профиль экрана (`screens/<id>.yaml`) — заполнять по ТЗ площадки
Обязательно узнать у площадки/подрядчика по экрану:
- Полное разрешение холста (px), из каких экранов/поверхностей состоит, их
  расположение (пиксельная карта, PDF/PNG с координатами).
- Шаг пикселя (pitch, мм), физический размер, яркость, частота обновления.
- Медиасервер и его версия; как он принимает контент: один холст или нарезка
  по выходам; кодек, контейнер, альфа, частота кадров.
- Процессоры (Novastar/Brompton) и выходы: размеры каждого выхода.
- Дистанция зрителей (ближняя/дальняя), точки обзора.
- Ограничения: максимальная яркость, запрет на стробы (эпилепсия), длительности.
Без этих данных профиль помечается `status: draft`, и в отчёте перечисляются
открытые вопросы. **Не выдумывать цифры.**

## Холст и производство
- Работаем в полном холсте 1:1, если программа тянет; иначе в масштабе с
  кратным коэффициентом (1:2), финал — апскейл нежелателен: лучше рендер секциями.
- Неровные/составные экраны: композиция = общий холст по пиксельной карте,
  зоны вне экранов — чёрные (guide-слой с маской карты).
- Fps: как требует медиасервер (обычно 25/50 или 30/60); не мешать.

## Кодеки (ориентиры)
| Кодек | Когда | Заметки |
|---|---|---|
| HAP / HAP Q / HAP Alpha | Resolume, Watchout, Disguise, TouchDesigner | быстрое декодирование GPU; размер кратен 4 |
| NotchLC | Disguise, Notch | качество выше HAP Q |
| ProRes 422 HQ / 4444 (+альфа) | универсальная сдача, мастер | Disguise понимает; тяжелее для 8K+ |
| DXV3 | Resolume | |
| PNG/TIFF/EXR секвенции | мастер, очень большие холсты | для архива и пересборки |
Точный кодек и параметры — **только из профиля экрана**.
Нарезка и перекодирование: `python tools/deliver.py <master> --screen <profile>` (ffmpeg;
HAP через ffmpeg `-c:v hap`, ProRes — `prores_ks`).

## Чек-лист сдачи (`08_delivery/delivery.md`)
□ разрешение каждого файла = выход/холст из профиля □ fps □ длительность и
кадр-в-кадр синхрон всех частей □ кодек/альфа/контейнер □ цветовое пространство
□ имена файлов по шаблону площадки □ тестовый прогон (или проверка в
ffprobe + контактный лист по стыкам) □ версия и дата □ инструкция воспроизведения
