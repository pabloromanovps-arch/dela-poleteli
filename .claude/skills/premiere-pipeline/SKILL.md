# Premiere Pro пайплайн

## Возможности автоматизации
- Premiere 25+: UXP-скрипты/плагины (JavaScript). Панель-исполнитель
  `tools/premiere/dp_panel` — в планах (`ROADMAP.md`).
- Старые версии: ExtendScript через CEP-панель или ExtendScript Toolkit.
- Без скриптов: генерация **XML (FCP7 XML)** таймлайна из шот-листа и рендеров;
  File → Import открывает её как обычный редактируемый проект. Это самый
  надёжный путь «одной кнопкой». Генератор `tools/premiere/xml_timeline.py` —
  в планах (`ROADMAP.md`).

## Правила
- Секвенция по параметрам профиля экрана (разрешение, fps).
- Монтаж: склейки на маркерах бит-сетки (импортируются как маркеры секвенции в XML).
- Версии из таблиц: одна секвенция = одна строка таблицы, имена `OUT_<template>_<id>`.
- Экспорт через Media Encoder пресетами `DP_*.epr` (сохранить из AME в `tools/premiere/presets/`).
