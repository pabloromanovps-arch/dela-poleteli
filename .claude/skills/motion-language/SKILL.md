# Язык движения

## Суть
Движение — такая же часть стиля, как шрифт. В библии проекта фиксируется
**пресет пластики**, и все анимации используют только его.

## Пресеты (выбери один базовый, второй — для акцентов)
| Пресет | Характер | Кривая (cubic-bezier) | Типичные длительности |
|---|---|---|---|
| `precise` | технологично, дорого | (0.7, 0, 0.2, 1) — expo in-out | 12–20 кадров |
| `confident` | статусно, уверенно | (0.3, 0, 0, 1) — сильный ease-out | 15–30 кадров |
| `soft` | тепло, человечно | (0.45, 0, 0.25, 1) | 20–40 кадров |
| `punchy` | спорт, энергия | (0.9, 0, 0.1, 1) + overshoot 3–6% | 6–12 кадров |
| `cinematic` | кино, масштаб | (0.4, 0, 0.1, 1), длинные хвосты | 40–120 кадров |
Длительности даны для 50 fps; пересчитывай под fps профиля экрана.

## Правила
- Никакого линейного движения (кроме постоянного дрейфа/вращения) и никакого
  дефолтного easy-ease 33%.
- Вход быстрее выхода не бывает: объекты **входят** с ease-out, **уходят** с ease-in.
- Каскад (stagger): 2–4 кадра между элементами, порядок — по иерархии чтения.
- Перекрытие (overlap): вторичные элементы стартуют до конца первичных.
- Одно главное движение за раз. Всё остальное — дыхание (микродрейф 0.5–2%).
- Масштаб движения соизмерим с экраном: на 30-метровом экране быстрое
  панорамирование вызывает дискомфорт — скорость ≤ ширины экрана за 2–3 с.
- Акценты ставятся на биты (см. `music-sync`), переходы — на такты/фразы.
- Переходы: 1–2 типа на весь проект (match cut, wipe по форме, свет, морф).

## Реализация в After Effects
- Кривые задаются через `KeyframeEase` скриптом (`tools/ae/lib/easing.jsxinc`):
  функция `applyBezier(prop, x1, y1, x2, y2)` переводит cubic-bezier в
  speed/influence AE.
- Overshoot/инерция — выражения из той же библиотеки, а не ручные ключи.
- Контроллер проекта: нуль `CTRL_motion` со слайдерами `speed_mult`, `stagger_frames`
  — глобальная правка темпа одной цифрой.

## Реализация в Blender
- Ключи с `interpolation='BEZIER'`, хэндлы рассчитываются из того же cubic-bezier
  (`tools/blender/lib/easing.py`).

## Ревью движения
Смотри на 50% скорости и покадрово: нет ли рывков, «плавающих» объектов, одинаковых
таймингов у всех, мёртвых пауз, движения против направления чтения.
