# Дизайн-контроль

## Входные данные (пути — от папки проекта `projects/<id>/`)
Обязательно: кадр/шот, `ai/bible/look.md`, `ai/bible/style_tokens.yaml`.
Желательно: запись шота в `ai/shots/shots.yaml` и сценарий сцены (оси
«Композиция» и «Эмоция»), профиль экрана (ось «Техника»), запись в
`ai/prompts/library.yaml` (происхождение кадра), соседние шоты (ось «Стык»).
Чего нет — ось помечается **«без данных»**, а не оценивается наугад.

## Объективные замеры
`python tools/frame_stats.py <кадр> --bible ai/bible/look.md [--screen <профиль>]` —
яркость по зонам (верх/центр/низ), доля тёплых/холодных пикселей, пересветы и
провалы, доли цветов палитры, разрешение против профиля. Цифры — в обоснование
оценок.

## Рубрика (1–10)
| Ось | Вопрос |
|---|---|
| Соответствие библии | свет, палитра, материал, оптика как в `look.md`? |
| Композиция | главное читается за 1 с, баланс, воздух, крупность как в шот-листе |
| Персонаж / мир | все неизменные признаки на месте (continuity) |
| Эмоция и смысл | кадр делает то, ради чего он в сценарии |
| Чистота | нет артефактов из каталога ниже |
| Движение (для шотов) | одно ясное движение, без «плавания» и морфинга |
| Техника | разрешение, резкость, шум, бэндинг, fps |
| Стык | монтируется с соседними шотами по свету, цвету, направлению |

Неприменимые оси («Движение» для кадра, «Стык» без соседей) — **н/п**, в решение
не входят.

## Вердикт
- **Принято** — все применимые оси ≥ 8, нет ❌, нет нарушений запретов библии.
- **Доработка** — любая ось < 8 или нарушен запрет библии, но идея кадра и
  основа (композиция/персонаж) годятся; правка конкретная и выполнимая.
- **Брак** — ❌-артефакт, который не лечится ретушью/композом; или ≥ 3 осей ≤ 4;
  или кадр не делает свою задачу в сценарии. Перегенерация с новой постановкой.

## Кому вернуть
| Проблема | Кадр-генерация | 3D-рендер | Видео-шот |
|---|---|---|---|
| Свет, палитра, материал, композиция | prompt-director | cg-generalist | ai-cinematographer |
| Движение, морфинг, мерцание | — | cg-generalist | ai-cinematographer |
| Персонаж/мир не совпадает | continuity-supervisor + prompt-director | cg-generalist | continuity-supervisor + ai-cinematographer |
| Текст, логотип | designer / motion-designer (графикой поверх) | | |
| Ошибка повторяется в серии | look-developer через art-director (стиль-токены, негатив, референсы) | | |
Происхождение — из `ai/prompts/library.yaml`. Нет записи → вернуть
art-director с пометкой «нет записи в библиотеке — нарушение процесса».

## Каталог артефактов (блокеры — ❌)
- ❌ руки/пальцы: число, слияние, неестественные суставы
- ❌ лица: асимметрия, «плывущие» черты в движении, мёртвые глаза, зубы
- ❌ текст и логотипы: искажённые буквы (текст делаем графикой поверх, не генерим)
- ❌ морфинг: объекты меняют форму/число во время шота
- ❌ нарушение физики, которое не задумано (ноги сквозь пол, тени не туда)
- мерцание текстур, «кипящие» детали фона
- «ИИ-глянец»: пластиковая кожа, пересвеченная резкость, перенасыщенность
- стилевой дрейф: кадр «из другого фильма»
- повторяющиеся паттерны, клоны в толпе

## Запись результата
- `ai/control/log.md` — одна строка-сводка в таблице:
  `дата | id | вердикт | мин. ось | главная проблема | кому`.
- `ai/control/<id>.md` — подробно: оценки по осям с обоснованием и замерами,
  список правок (кому, что), ссылка на кадр.

## Обратная связь в систему
Каждые ~20 проверок — сводка: какие ошибки повторяются. Повторяющаяся ошибка
лечится в стиль-токенах, негативе, референсах или шот-дизайне — предложение
отправляется art-director. Правка отдельных кадров без исправления причины — брак
процесса.
