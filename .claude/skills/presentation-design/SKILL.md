# Презентации

Презентация — продающий артефакт стадий 02–03. Плохая подача убивает хороший
концепт. Делаем как студии уровня Buck/ManvsMachine: мало текста, крупные
кадры, ясная логика.

## Сборка (редактируемо!)
`deck.yaml` → `python tools/deck/build_deck.py deck.yaml --brand <client|studio> --out deck.pptx --pdf --preview`
- PPTX полностью редактируемый (тексты, картинки — обычные объекты).
- `--pdf` — PDF через LibreOffice; `--preview` — контактный лист слайдов
  (`*_preview.png`) для самопроверки.
- Тема (цвета, шрифты, логотип) — из `brands/<x>/brand.yaml`.
Типы слайдов: `cover, section, statement, text, image, image_grid, compare,
palette, typography, quote, timeline, end` (пример: `examples/deck/concept_deck.yaml`).

## Структуры
**Концепт / питч (стадия 02)** — 10–18 слайдов:
обложка → задача в одном предложении → инсайт/контекст (площадка, зритель) →
для каждого направления: идея (statement) → референсы с пометками →
ключевые кадры/фреймы → палитра и типографика → язык движения (раскадровка или
GIF-ссылка) → сравнение направлений (compare) → рекомендация → план и сроки → финал.

**Стайлфреймы (03)**: обложка → напоминание идеи → фреймы по одному на слайд
во весь экран → детали (типографика, палитра, движение) → экран в контексте
площадки (мокап зала) → следующий шаг.

**Кейс**: задача → идея → процесс (2–3 слайда) → результат (кадры, видео) → цифры.

**Брендбук**: см. `brand-book` (C), разделы 1–7.

## Правила вёрстки
- Один слайд — одна мысль. Заголовок — утверждение, а не тема
  («Свет рождает логотип», а не «Концепция»).
- Текста ≤ 25 слов на слайд (кроме приложений). Картинки — во весь слайд или
  по сетке, без рамок и теней.
- 16:9, поля ≥ 6% ширины, сетка 12 колонок; выравнивание по сетке, не «на глаз».
- Шрифты и цвета — только из бренда; акцентный цвет — для одного элемента на слайде.
- Ритм: чередовать «громкие» (statement, полноэкранный кадр) и «тихие» слайды.
- Финальный слайд — следующий шаг и контакт, а не «Спасибо».

## Самопроверка
Собери `--preview`, посмотри лист: читается ли история только по заголовкам?
нет ли перегруженных слайдов, вылетов текста, разнобоя отступов? Исправь → пересобери.
