# Синхронизация с музыкой

## 1. Анализ
`python tools/audio/beats.py <track.wav> --fps <fps профиля> --out 04_board/beatgrid.json`
Даёт: темп, биты (время + кадр), сильные доли (1-я доля такта), такты, онсеты
(удары), огибающую громкости, границы секций (куплет/дроп). Требуется `librosa`
(`pip install -r tools/requirements.txt`).

Проверь вручную: темп иногда определяется вдвое (120 vs 60). Сверь с ощущением и
при необходимости укажи `--bpm`.

## 2. Иерархия синхронизации
| Музыкальное событие | Что на него ставим |
|---|---|
| Секция / дроп | смена сцены, главный переход, смена палитры |
| Такт (downbeat) | смена шота, появление ключевого элемента |
| Доля (beat) | каскады, мелкие акценты, пульсация |
| Онсет (удар) | вспышки, удары камеры, частицы |
| Огибающая громкости | интенсивность свечения, масштаб, скорость — через выражение |

Правила:
- Не всё в бит. Если каждая доля что-то двигает — это мельтешение. Акцент там,
  где он в музыке.
- Визуальное событие ставь на 1–2 кадра **раньше** удара — глаз воспринимает
  движение с задержкой, так ощущается точнее.
- Переход начинается до такта и «приземляется» в такт.

## 3. Маркеры
- AE: `tools/ae/import_beatgrid.jsx` — создаёт маркеры на аудиослое и нуль
  `CTRL_audio` со слайдером `env` (громкость) для выражений.
- Blender: `tools/blender/import_beatgrid.py` — маркеры таймлайна + кастомное
  свойство `env` с ключами.
- Раскадровка: в `board.md` каждый шот имеет `in`/`out` в тактах, а не секундах.

## 4. Если музыки ещё нет
Работай по временной бит-сетке (`--bpm 120 --duration 60`) — так шоты уже
будут на правильных местах, когда придёт трек.
