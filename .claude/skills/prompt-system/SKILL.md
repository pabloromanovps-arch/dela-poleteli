# Система промптов

## Структура промпта (порядок блоков)
1. **Сюжет шота** — кто/что, действие, эмоция (из `shots.yaml`).
2. **Композиция** — крупность, ракурс, расположение в кадре, соотношение сторон.
3. **Свет сцены** — из color script для этой сцены.
4. **Стиль-блок** — дословно из `style_tokens.yaml` (style, light, camera, color).
5. **Негатив** — из библии + специфичный для шота.
Конкретика вместо оценок: «тёплый контровой свет из окна слева, пыль в луче»,
а не «красивый кинематографичный свет».

## Консистентность
- Персонаж: эталонные изображения из `bible/characters/` как референс
  (character/face reference), одинаковое описание неизменных признаков, при
  длинных проектах — обученная модель персонажа (LoRA и аналоги), если модель
  это поддерживает.
- Стиль: стиль-референс из `bible/refs/` + неизменный стиль-блок.
- Композиция: референс-схема от раскадровщика.
- Фиксируй сид у удачного варианта и меняй по одному параметру за раз.

## Библиотека `ai/prompts/library.yaml`
```yaml
- id: sc02_sh030_v03
  shot: sc02_sh030
  model: "<сервис и версия>"
  prompt: "..."
  negative: "..."
  seed: 123456
  refs: {character: bible/characters/hero/front.png, style: bible/refs/r04.png}
  params: {aspect: "16:9", steps: null, guidance: null}
  result: ai/gens/sc02_sh030/v03_*.png
  verdict: selected | rejected
  reason: "..."
```

## Выбор модели
Модели и их возможности меняются каждые несколько месяцев. Перед проектом
проверь актуальные и запиши выбор в `ai/prompts/models.md` по критериям:
фотореализм · стилизация/иллюстрация · текст в кадре · консистентность персонажа
по референсу · разрешение · коммерческие права на результат · доступ по API.
