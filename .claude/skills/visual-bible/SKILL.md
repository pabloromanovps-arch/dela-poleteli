# Визуальная библия (ai/bible/)

Библия нужна, чтобы 200 кадров от разных моделей и попыток выглядели как один
фильм. Пишется так, чтобы её мог применить и человек, и промпт.

## Состав
1. **look.md** — словами, конкретно:
   - эпоха и мир; материалы и фактуры; свет (жёсткий/мягкий, направление,
     цветовая температура, источники); оптика (фокусное, глубина резкости,
     дисторсия); носитель (плёнка 35 мм / цифра / анимация / иллюстрация, зерно);
     композиционные правила; палитра по ролям;
   - **запреты**: что ломает мир (неон, если мир тёплый; «ИИ-глянец»; лишние детали).
2. **style_tokens.yaml** — фиксированные формулировки для промптов:
   ```yaml
   style: "..."       # носитель, материал, общий вид — одна строка, не меняется
   light: "..."
   camera: "..."
   color: "..."
   negative: "..."    # что исключаем всегда
   per_model: {}      # уточнения под конкретные модели
   ```
3. **color_script** — полоса цветов по сценам + эмоциональная кривая; каждая
   сцена: доминанта, акцент, контраст, время суток.
4. **Персонажи** `characters/<id>/`: эталонные изображения (анфас, профиль, ¾,
   полный рост, 2–3 эмоции), `sheet.md` с неизменными признаками и допустимыми
   вариациями (костюм по сценам).
5. **Мир** `world/<локация>/`: ракурсы, план локации, свет по времени суток.
6. **refs/** — эталонные кадры «так выглядит наш мир» с подписью, что в каждом
   эталон (свет / фактура / композиция).

## Как проверить, что библия работает
Тест: 6 разных шотов (общий, крупный, ночь, день, персонаж, пустая локация) по
одним стиль-токенам → контактный лист → выглядит как один фильм? Нет → правим
токены, а не отдельные кадры.
